赛琳娜 DeepSeek 桌宠 · 部署、保存与迁移

首次使用：
1. 安装官方 DeepSeek Harness 并登录一次。
2. 把完整包解压到可写目录（例如 D:\赛琳娜DeepSeek桌宠）。
3. 双击「一键部署.cmd」：检查文件，安装 Harness 连接插件（需要先从托盘完全退出 Harness，脚本会提示），创建桌面和开始菜单快捷方式并启动赛琳娜。
4. 重新打开 Harness，新任务启动后自动跟随；可以在连接设置中选择会话。

也可以直接启动“赛琳娜DeepSeek桌宠启动.exe”，再在 设置 → 连接 DeepSeek → 安装 / 更新 Harness 连接插件。

设置自动保存。右键 → 设置 → 保存与迁移，可立即保存、导出配置素材包或 Windows 便携完整包。
完整包携带运行程序、GIF、音频、每条字幕、字体、全部桌宠设置和 Harness 连接插件安装工具。

换电脑：在新电脑解压后，同样双击「一键部署.cmd」。
连接设置里的自动启动选项会保存；新电脑第一次手动启动桌宠后恢复。
连接路径、窗口位置和当前会话在完整包中重置，自动适配新电脑。
桌宠包不会携带 DeepSeek 的账户、密钥、聊天、余额缓存。

移除连接插件：退出 Harness 后，用其 resources/runtime/cli/bin/dsh.cmd 执行
plugin --profile desktop remove dsh-selena-pet
然后重新打开 Harness。桌宠设置和素材不会被删除。

首次正常启动 Windows 版会创建桌面快捷方式。误删后：设置 → 保存与迁移 → 创建桌面快捷方式，或再运行一次「一键部署.cmd」。

设置 → 版本与更新可选自动／GitHub／镜像加速；发现新版时可一键下载、校验签名、更新并重启。连接页面可设置随客户端完全退出而关闭。
